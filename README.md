#### Description:

WonderWhiz Academy is an interactive educational quiz platform designed for children from Kindergarten to Grade 6. The project was created as my final project for CS50x and aims to make learning more engaging, enjoyable, and accessible through gamified educational activities.

The main purpose of this project is to encourage children to practice academic subjects in a fun and interactive way rather than relying only on traditional learning methods. The platform combines education and gameplay by allowing users to answer quiz questions, track scores, and interact with a colorful and child-friendly interface.

The application includes four core subjects:
- English
- Mathematics
- Science
- General Knowledge

Users can select their grade level and preferred subject before beginning a quiz round. Each round contains four questions specifically designed for the selected level and subject. The game also includes a score tracking system that allows users to monitor their progress and performance throughout gameplay.

One of the main design goals of WonderWhiz Academy was to create an interface suitable for younger learners. The project uses playful buttons, bright visuals, images, and simple navigation to maintain user engagement while keeping the platform easy to use for children.

This project was developed as a web-based application and published online using GitHub Pages.

Technologies used in this project include:
- HTML
- CSS
- JavaScript
- GitHub Pages

HTML was used to structure the website and organize the content of the application. CSS was used to style the interface, improve the visual design, and create an engaging appearance for users. JavaScript was used to implement the interactive quiz logic, navigation system, score tracking, and gameplay functionality.

One challenge during development was organizing educational content for multiple grades and subjects while keeping the gameplay simple and user-friendly. Another challenge was balancing educational value with entertainment so that the platform remained both useful and enjoyable for children.

Throughout development, I also focused on improving accessibility, navigation, and responsiveness to ensure a smoother user experience.

For future improvements, I would like to add:
- More grade levels and subjects
- Additional quiz rounds and question sets
- Sound effects and animations
- User progress saving
- Achievement badges and leaderboards
- Personalized learning recommendations

This project helped me improve my understanding of web development, programming logic, problem-solving, and user interface design. It also allowed me to combine technology and education into a meaningful and interactive learning platform.

AI tools such as ChatGPT and Gemini were occasionally used for debugging assistance, coding guidance, and idea generation during development. However, the overall project design, implementation, and customization were completed independently.
